# Security Policy

## Supported Versions

We actively maintain and provide security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps:

1. **Do not create a public GitHub issue.**
2. Use GitHub's [Private Vulnerability Reporting](https://github.com/PanchalAnubhav/USvisa_approval_systmm/security/advisories/new) feature directly in this repository.
3. Alternatively, contact the repository maintainer via email with details about the vulnerability, reproduction steps, and potential impact.

### What to include in your report:
- A description of the issue and potential security impact
- Step-by-step reproduction instructions or proof-of-concept (PoC)
- Suggested mitigation or fix (if available)

### Response Timeline
- **Initial Response:** Within 48 hours
- **Status Update / Assessment:** Within 5 business days
- **Resolution / Patch:** Released as promptly as possible based on severity

Thank you for helping keep this project secure!
